# A2A vs. MCP — GitHub Pages

Sitio estático listo para publicar en GitHub Pages.

## Publicación rápida
1. Crea un repositorio en GitHub (por ejemplo `a2a-mcp`).
2. Sube todo el contenido de esta carpeta al repo (incluye `index.html`, `styles.css`, `script.js` y la carpeta `assets`).
3. En **Settings → Pages**, elige **Deploy from branch** → **main** → carpeta **/** (root). Guarda.
4. Espera a que se construya la página y visita `https://<tu-usuario>.github.io/a2a-mcp/`.

> Puedes reemplazar/añadir imágenes en `assets/` (por ejemplo `arquitectura_a2a_mcp.png`).
